# K리그 우승·승격 확률

매일 오전 7시(한국 시간) GitHub Actions가 Daum 스포츠에서 K리그1·2 경기 결과와 일정을 받아 `data/`를 갱신하고,
그날 확률을 `data/history.json`에 기록합니다. 페이지(`index.html`)는 열 때마다 `data/`를 읽어 직접 시뮬레이션합니다.

- 수동 실행: Actions 탭 → 데이터 갱신 → Run workflow
- 부상·결장 반영: `data/injuries.json`을 고칩니다. 형식은 아래와 같고, 다음 갱신 때 반영됩니다.

```json
{"k1": [{"team": "전북", "player": "선수명", "note": "무릎 부상", "source": "매체명 2026-10-14"}], "k2": []}
```

팀 이름은 Daum 표기(서울, 울산, 강원, 제주, 전북, 대전, 인천, 안양, 포항, 김천, 부천, 광주 /
수원, 수원FC, 서울E, 대구, 화성, 부산, 충남아산, 김포, 경남, 충북청주, 성남, 파주, 용인, 천안, 전남, 안산, 김해)를 씁니다.
